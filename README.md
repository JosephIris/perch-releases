# Perch releases

Installers and update packages for [Perch](https://buildwithperch.com), a native workspace for running coding agents (Claude Code first).

Download the latest from [Releases](https://github.com/JosephIris/perch-releases/releases/latest): `Perch-win-Setup.exe` for Windows, `Perch-osx-Setup.pkg` for macOS. Installed copies update themselves from here.

The source is private.
